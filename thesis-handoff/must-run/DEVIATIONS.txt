    (/#/clusterrole/mustrun-cr) lets the namespace selector add the missing ?namespace= query by

    setDefaultQueryParams_), which drops the record name and lands on the list screen. Every
    in-app link carries the namespace query (queryParamsHandling: 'preserve'), so the edges were
    rebuilt with ?namespace=must-run on every source URL (edges.mjs --query) and all 125 checks
    were run again; the second pass is the one reported. This changes the driver's input, not
    the extractor, the graph or the must tier.
